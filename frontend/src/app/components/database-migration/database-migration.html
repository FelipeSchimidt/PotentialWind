Arquitetura de Portabilidade

A persistência foi construída com abstração transparente no DatabaseProviderExtensions.cs. Todas as entidades utilizam tipos de dados compatíveis tanto com SQLite quanto com MySQL (precisões ANSI standard decimal(18,2), chaves autoincrementadas, índices e restrições de integridade referencial).

Pacote Pomelo.EntityFrameworkCore.MySql 9.0 instalado

Drivers oficiais de alta performance para MySQL e MariaDB.

Inicialização Automática com SeedData

Ao apontar para o MySQL, todas as tabelas e dados prévios são criados automaticamente.
